# Table Forge · Кузница таблиц

Модуль для Foundry VTT v13–v14: удобная работа со случайными таблицами (RollTable).
Работает поверх родных таблиц — если модуль выключить, все таблицы остаются обычными таблицами Foundry.

## Установка

Foundry → Add-on Modules → Install Module → Manifest URL:

```
https://github.com/samroaleksej-bit/table-forge/releases/latest/download/module.json
```

## Возможности

- **Шесть тем оформления**: Кузница, Проводник, Гримуар, Колода, Терминал, Пульт. Выбор при первом запуске, у каждого игрока своя.

- **Библиотека** (`Alt+T` или кнопка в сайдбаре таблиц): папки мира и компендиумы, избранное, недавние.
- **Поиск** по названию и тексту результатов, без учёта ё/е, с опечатками и неверной раскладкой.
- **Бросок в один клик**: кнопка 🎲, двойной клик по строке, `Enter` в поиске бросает первую найденную.
- **Карточка в чате**: число, результат, ссылки, кнопки «Перебросить», «Ещё раз», «Показать игрокам».
- **Пакетный импорт** `fvtt-RollTable-*.json`: дубли не создаются, папки сохраняются, отчёт по каждому файлу.

Системно-независимый (dnd5e, Cyberpunk RED и любые другие).

## Разработка

Без сборщика и зависимостей: ES-модули, Handlebars, CSS.

```
node --test "tests/*.test.mjs"
```

Тесты импорта используют экспорты из папки над репозиторием (или `TF_DATA_DIR`); в CI они пропускаются.
`mock/` — мок-окружение Foundry для проверки интерфейса в браузере.

Релиз собирается GitHub Actions при изменении `version` в `module.json` на `main`.
